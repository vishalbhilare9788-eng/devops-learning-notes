# My Learning Notes — Terraform, Session-wise Log

Mirrors the ArgoCD/Kubernetes tracks' convention (`F:\Claude code\ArgoCD\My Learning Notes\`,
`F:\Claude code\K8s Prepration\My Learning Notes\`).

## Naming convention
`NN-topic-name.md` — e.g. `01-terraform-workflow.md`, `02-providers-and-state.md`

## How this works
1. You tell me you're starting a "Terraform chapter" and dictate what you learned (and/or share
   screenshots).
2. I write it up here as `NN-topic-name.md`, cleaned up but kept in your voice.
3. A polished, print-ready PDF version goes into `PDF/` — same filename, `.pdf` instead of `.md`.
4. Any screenshots from that session get bundled into their own gallery PDF in `Screenshots/`
   (`NN-topic-name-screenshots.pdf`) — matched from `C:\Users\Lemnovo\Pictures\Screenshots\` by
   timestamp, same as the other tracks.
5. Reusable reference content (concepts, full command reference) gets merged into
   `../terraform-master-notes.md` as a new or expanded section.
