# My Learning Notes — AI, Session-wise Log

Mirrors the Kubernetes, ArgoCD and Terraform tracks' convention (`F:\Claude code\K8s Prepration\My Learning Notes\`).

Goal of this track: understand AI end to end, from what it is and the main areas inside it
to how it actually runs in production, one chapter at a time.

## Naming convention
`NN-topic-name.md`, e.g. `01-what-is-ai.md`, `02-machine-learning-basics.md`

## How this works
1. You tell me you're starting an "AI chapter" and dictate what you learned (and/or share screenshots).
2. I write it up here as `NN-topic-name.md`, cleaned up but kept in your voice.
3. A polished, print-ready PDF version goes into `PDF/`, with the same filename but `.pdf` instead of `.md`.
4. Any screenshots from that session get bundled into their own gallery PDF in `Screenshots/`
   (`NN-topic-name-screenshots.pdf`), matched from `C:\Users\Lemnovo\Pictures\Screenshots\` by
   timestamp, same as the other tracks.
5. Reusable reference content (concepts, architectures, commands, code) gets merged into
   `../ai-master-notes.md` as a new or expanded section.
